# RupAI ERP — Admin Dashboard

Tea estate management admin dashboard built with React, Tailwind CSS, Lucide React, and Recharts.

## Run

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (usually `http://localhost:5173`).

## Stack

- Vite + React (JavaScript)
- Tailwind CSS v4
- lucide-react
- recharts
